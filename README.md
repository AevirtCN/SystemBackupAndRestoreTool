# SystemBackupAndRestoreTool
基于Python的系统备份还原工具，提供图形界面，支持Windows平台的文件和系统备份还原操作

## 版本

当前版本：V0.2.0

### 更新内容

- **界面优化**：重新设计界面布局，确保所有元素完整显示，提升美观度和易用性
- **性能提升**：实现多线程并行处理，添加超级分段处理技术，大幅提升备份还原速度
- **格式支持**：增加对ghost、ATIH等主流备份格式的支持
- **功能增强**：添加GPT分区的4K对齐备份选项，解决4K对齐问题
- **技术改进**：采用模块化设计，完善错误处理机制，实现详细的进度反馈


## 功能特点

- **图形界面**：使用tkinter实现的直观图形界面，操作简单易用
- **备份功能**：支持选择目录进行备份，可选择是否压缩备份文件
- **还原功能**：支持从备份文件或目录进行还原
- **进度显示**：备份和还原过程中显示实时进度
- **错误处理**：完善的错误处理机制，确保操作安全可靠
- **无依赖**：仅使用Python标准库，无需安装额外第三方包

## 安装要求

- Python 3.14+
- Windows操作系统
- 已添加Python环境变量

## 使用方法

1. **克隆或下载项目**
   ```bash
   git clone https://github.com/yourusername/SystemBackupAndRestoreTool.git
   cd SystemBackupAndRestoreTool
   ```

2. **运行工具**
   ```bash
   python main.py
   ```

3. **备份操作**
   - 在"备份"标签页中，点击"浏览"按钮选择要备份的源目录
   - 选择备份文件保存路径
   - 选择是否压缩备份（默认开启）
   - 点击"开始备份"按钮

4. **还原操作**
   - 在"还原"标签页中，点击"浏览"按钮选择备份文件或目录
   - 选择还原目标路径
   - 点击"开始还原"按钮
